# jj-musubi hub

Run a [jj-musubi](https://www.serpentine.com/software/jj-musubi/) hub on Home Assistant, so
your laptops and desktops can keep their [Jujutsu](https://jj-vcs.github.io/jj/) repositories
in sync through a machine that is always on.

The add-on runs `musubi hub` and an ssh server that machines reach it through. See the
Documentation tab for setup.

Supports amd64 and aarch64.
